# First fused confirmation limits

The four polynomial cases include valid PyTorch and CuPy controls. The two sensitivity cases rejected CuPy because the harness passed a Fraction to a CuPy scalar operation. They cannot support a claim against the strongest standard GPU control. A fresh product suite converts the parameter at the same FP64 boundary as the other executors, rechecks every endpoint and reruns all selected comparisons. The v1 data are retained, not overwritten.
