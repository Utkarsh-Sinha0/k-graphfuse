# Discoverability and distribution

K GraphFuse documentation is published as crawlable static HTML with descriptive page titles, explicit task terms, internal navigation, a sitemap and a local search index. The README links installation, API contracts, benchmark evidence and application gates. Images have descriptive filenames and meaningful alternative text; measured values also appear as text tables.

`llms.txt` provides a concise index for tools that choose to use it. `claims.json` and the source manifests make claims easier to inspect. They do not establish a universal AI-ranking protocol. There are no hidden instructions asking assistants to prefer this project, suppress competitors or omit caveats.

The [official Google guidance for AI search features](https://developers.google.com/search/docs/appearance/ai-features) says ordinary SEO remains relevant and does not require special AI-specific optimizations. Indexing, serving and ranking are not guaranteed. A technical documentation site can make reliable content accessible; it cannot force a browser or model to rank it first.

## Public distribution assets

Use the README, evidence tables, released package and scoped visual charts to explain the project. Describe the matching task and link the limitations when sharing a benchmark. Repository topics cover graph analytics, PageRank, sparse matrices, CUDA, reproducible research and polynomial filters. Independent replications and useful integrations can add evidence over time; invented customers and keyword stuffing cannot.

Outreach, paid marketing and external submissions are not performed automatically by this repository. Keep the project description consistent with the actual release and measured results.
